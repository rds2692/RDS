El precio de una página web en Chile puede ir desde una landing page acotada hasta un proyecto corporativo con múltiples servicios, integraciones y contenido propio. Comparar sólo una cifra lleva a decisiones equivocadas: dos propuestas del mismo valor pueden incluir trabajos completamente distintos.

Antes de pedir una cotización, conviene separar el proyecto en cuatro partes: estrategia y arquitectura, diseño, desarrollo y puesta en marcha. A eso pueden sumarse contenido, fotografía, integraciones, hosting, dominio, mantención y posicionamiento.

## ¿Qué determina el precio de una página web?

### Cantidad y complejidad de las páginas

Una landing page presenta una oferta concreta. Un sitio corporativo suele necesitar inicio, servicios, empresa, casos, contacto y páginas independientes para cada servicio importante.

La diferencia no está sólo en la cantidad de pantallas. Cada página adicional requiere estructura, redacción, diseño, desarrollo y revisión. También aumenta la necesidad de enlazado interno y coherencia visual.

### Estrategia y contenido

Una web no empieza en Figma ni en el código. Empieza entendiendo qué vende el negocio, quién necesita el servicio, qué preguntas aparecen antes del contacto y qué información debe mostrarse.

Cuando el cliente entrega contenidos completos, esa etapa puede avanzar más rápido. Cuando hay que investigar, ordenar, redactar o corregir información, el trabajo aumenta. También sucede si participan varias personas o si la oferta todavía no está definida.

### Diseño y desarrollo

Una plantilla adaptada tiene un costo distinto a una dirección visual creada para la marca y una experiencia construida desde la arquitectura del sitio. En desarrollo, el precio cambia si se necesitan catálogos, agendas, integraciones, automatizaciones, acceso privado o funciones específicas.

No toda función mejora el negocio. Una buena propuesta debería explicar qué problema resuelve cada componente y qué se puede dejar para una segunda fase.

## ¿Cuánto cuesta una web en RDS?

RDS publica planes base en pesos chilenos para hacer más transparente el punto de partida:

- **Web Starter:** desde $250.000 CLP para una landing page de hasta cinco secciones.
- **Web Business:** desde $490.000 CLP para un sitio corporativo de hasta seis páginas.
- **Web Growth:** desde $750.000 CLP para una arquitectura de hasta diez páginas con una base SEO más completa.

Estos valores corresponden a proyectos de pago único y no incluyen posicionamiento mensual, redacción ilimitada, páginas locales múltiples, campañas, hosting, dominio, licencias o integraciones especiales. El alcance final se confirma por escrito.

Puedes revisar la [comparación completa de precios](/precios/) y los entregables de cada alternativa.

## ¿Qué debe incluir una cotización de diseño web?

Una cotización útil debería responder:

1. Cuántas páginas y secciones incluye.
2. Qué contenido aporta el cliente y qué contenido produce RDS.
3. Cuántas rondas de revisión existen.
4. Qué tecnología se utilizará y cómo se administrará el contenido.
5. Qué integraciones están incluidas.
6. Cómo se manejan dominio, hosting, copias y accesos.
7. Qué pruebas se realizan antes de publicar.
8. Qué servicios quedan excluidos.
9. Cuándo se paga y bajo qué condiciones.
10. Qué ocurre después del lanzamiento.

Un presupuesto que sólo dice “página web profesional” no permite comparar.

## Landing page, web corporativa o tienda online

La **landing page** sirve para concentrar una campaña o servicio. Es útil para validar una oferta o presentar un negocio pequeño.

La **web corporativa** organiza varios servicios y presenta a la empresa con más contexto. Una [web para empresas](/diseno-web-empresas/) necesita una arquitectura que permita crecer y conectar áreas de servicio.

La **tienda online** suma catálogo, pagos, stock, despacho y otros procesos operativos. Su presupuesto depende de esas funciones y no sólo de la cantidad de productos.

## ¿Cuánto cuesta una página por comuna?

Una página local no es una web completa. Si se incorpora dentro de un sitio existente, debe tener contenido propio, cobertura real y utilidad para el visitante. En RDS, cada página local se cotiza por cantidad y complejidad.

No recomendamos crear decenas de páginas cambiando sólo el nombre de la comuna. Google puede tratar ese patrón como contenido duplicado o páginas puerta. Es preferible partir por las zonas donde el negocio tiene cobertura y capacidad real de responder.

Puedes conocer el trabajo de [diseño web por comuna](/diseno-web-santiago/) y la diferencia entre una página local y el posicionamiento en Google Maps.

## ¿Cuánto cuesta mantener y posicionar una web?

Publicar una web no detiene el trabajo digital. Pueden existir actualizaciones técnicas, copias, cambios de contenido, mejoras de rendimiento, analítica y posicionamiento.

El SEO mensual no incluye necesariamente desarrollo, redacción ilimitada o correcciones estructurales. Cada plan debe indicar cuántas páginas, palabras clave y contenidos contempla. Tampoco corresponde prometer una posición concreta en Google.

Antes de contratar posicionamiento, revisa si el sitio puede rastrearse e indexarse y si la propuesta explica [qué revisará cada mes](/seo/).

## Cómo elegir la propuesta más razonable

La opción más barata no siempre es la de menor riesgo. Si falta estructura, contenido o preparación técnica, el costo reaparece en correcciones o en una segunda web.

La opción más cara tampoco garantiza resultados. Revisa qué necesitas hoy, qué puedes administrar y qué parte del proyecto puede esperar. Un sitio bien pensado puede empezar acotado y crecer sobre una arquitectura preparada.

Antes de contratar, comprueba que la agencia explique también qué no incluye y que exista un proceso para [conversar sobre tu proyecto](/contacto/) sin promesas que no puedan verificarse.

## Tres escenarios de presupuesto

### Una landing page para validar una oferta

Es apropiada cuando existe un servicio principal, una campaña o una idea que se quiere probar. El trabajo se concentra en una página con mensaje, secciones, formulario y una acción medible.

El presupuesto puede mantenerse acotado si el contenido está listo, la marca no necesita una exploración visual profunda y no hay integraciones complejas. Si hay que investigar la oferta, redactar desde cero o desarrollar funciones específicas, el alcance aumenta.

### Un sitio corporativo para varios servicios

Una empresa con distintas áreas necesita más que varias secciones dentro de una sola página. Requiere decidir qué servicios se agrupan, cuáles merecen una página propia y cómo se evita que compitan entre sí.

El trabajo incluye arquitectura, navegación, diseño de componentes, contenido y enlaces internos. También pueden aparecer requisitos de analítica, formularios, integración con CRM o publicación de casos de estudio.

### Una web preparada para crecer

Cuando el negocio espera sumar páginas locales, contenidos, nuevos servicios o funcionalidades, conviene diseñar una estructura que no obligue a reconstruir todo seis meses después.

Esto no significa contratar desde el primer día todas las funciones imaginables. Significa separar correctamente los módulos y documentar cómo se ampliarán.

## Cómo preparar el contenido antes de pedir una cotización

Reúne la siguiente información:

- Qué servicios son más importantes comercialmente.
- Qué preguntas hacen los clientes antes de contratar.
- Qué diferencia al negocio de otras alternativas.
- Qué casos, fotografías o testimonios pueden publicarse.
- Qué formularios, agendas o pagos se necesitan.
- Qué cuentas de dominio, hosting y analítica existen.
- Qué contenido debe conservarse.

No necesitas escribir la web completa, pero sí identificar el conocimiento que no está documentado. La falta de información suele producir más retrasos que el diseño.

## Errores que encarecen un proyecto

### Cambiar el alcance sin documentarlo

Agregar páginas, funciones o secciones sin una nueva estimación desordena el proyecto. Lo razonable es registrar qué cambia, cuánto afecta al calendario y cuál será el nuevo costo.

### No definir quién aprueba

Cuando varias personas opinan sin un responsable final, las revisiones se multiplican. Define quién entrega los contenidos, quién aprueba el diseño y quién autoriza la publicación.

### Comprar funciones que no se van a usar

Una plataforma con decenas de módulos no es mejor si el equipo no los necesita. Prioriza las funciones que reducen trabajo o ayudan a generar consultas.

### No revisar qué ocurre después de publicar

La entrega debe incluir accesos, instrucciones básicas, condiciones de soporte y un plan para los primeros ajustes. Una web no termina cuando el sitio deja de estar en desarrollo.

## Preguntas que cambian el presupuesto

- ¿La empresa necesita una o varias sedes?
- ¿Los servicios tienen precios públicos?
- ¿Los textos serán revisados por más de una persona?
- ¿Se requiere un blog con un flujo editorial?
- ¿Existen formularios conectados a un CRM?
- ¿Se publicarán proyectos individuales?
- ¿Se necesita reserva de horas?
- ¿La web actual tiene URLs que deben conservarse?

No existe un precio universal para una página profesional. Existe un alcance definido para un objetivo concreto. Si una propuesta no permite entender esa relación, conviene pedir más detalle antes de pagar.

## Cómo saber si una oferta económica sigue siendo razonable

Una propuesta económica puede ser válida cuando reduce alcance de forma explícita: menos páginas, contenido entregado por el cliente, una configuración más simple o menos integraciones. Deja de serlo cuando necesita recortar elementos indispensables para que la web cumpla su objetivo.

Por ejemplo, ahorrar en estructura puede obligar a rehacer las páginas cuando el negocio agrega servicios. Ahorrar en contenido puede dejar una web visualmente correcta que no explica la oferta. Ahorrar en pruebas puede producir formularios defectuosos o problemas de indexación después del lanzamiento.

La comparación útil no es “cuánto cuesta una página”, sino “qué debe lograr esta página y qué trabajo mínimo se necesita para conseguirlo con un riesgo aceptable”. Esa respuesta permite negociar alcance con criterio y no sólo rebajar una cifra.
